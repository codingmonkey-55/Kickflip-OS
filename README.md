# Kickflip-OS
Kickflip OS is a fast, creative, skater-inspired operating system designed to make computing fun and personal. With a bold interface, custom wallpapers, a unique GRUB boot experience, and a simple graphical installer, Kickflip OS delivers a smooth and exciting desktop experience for everyday use, creativity, and exploration.

cd Kickflip-OS && \
